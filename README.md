# 🏠 Interior Design Consultation & Booking App

A modern full-stack web application that makes interior design consultation booking simple, fast, and seamless.

🌐 **Live Demo:** [View Live Application](https://ramcharanc2211-source.github.io/interior-app-frontend/)  
💻 **GitHub Repository:** [View Source Code](https://github.com/ramcharanc2211-source/interior-app-frontend)

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔐 **Authentication** | User signup and login using Firebase Authentication |
| 🎨 **Designer Discovery** | Browse interior designers and their services |
| 👤 **Designer Profiles** | Explore experience, ratings, pricing, and services |
| 📅 **Smart Booking** | Book consultations using an interactive calendar |
| ⏰ **Time Slots** | View available and booked consultation slots |
| 🚫 **Booking Protection** | Prevent duplicate bookings for the same slot |
| 🔗 **REST API** | Communication between the Flutter frontend and backend |
| ☁️ **Cloud Database** | Store application data using MongoDB Atlas |
| 🚀 **Deployment** | Frontend hosted on GitHub Pages and backend deployed on Render |
